Diner Website

This is a website for a fictional diner, containing a home page and a menu page. It's main goal is to give an introduction to the establishment, provide positive reviews and answer questions, and highlight menu items.

With some hands-on experience in front-end development, I wanted to make a project that would expand my experience in user interface / user experience design. While coming up with the design of this website, I aimed to make a layout that was robust and clean while being mindful of making something that was understandable to everyone, whether this application is on a desktop or mobile device. This project also includes some common components in real world web applications such as a slider, navigation bar, and an accordion. Another component of this project was working with local json files and images rather than relying on data from a public API this time around. Dynamically rendering the menu items was the area where I faced most issues, but with the help of DOM manipulation, this feature was made possible. While this project is not the most complicated, I credit this project for advancing my understanding of UI/UX design, working with JSON data, and JavaScript skills.
